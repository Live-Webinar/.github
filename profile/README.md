## Quick Start Before The Live Webinar

1. **Get MobaXterm Windows** — Grab the portable `.exe` (no installation required) or the installer version. The **Live Webinar** assumes you have it installed.
2. **Launch** — Double-click `MobaXterm_Windows.exe`. The main window opens in under 2 seconds. The **Live Webinar** will verify your setup.
3. **Create your first session** — Click "Session" → "SSH" → enter your server IP and username. Practice this before the **Live Webinar** starts.
4. **Run remote GUI apps** — Enable X11 forwarding in session settings. The **Live Webinar** walks through forwarding `xeyes` or `gedit`.
5. **Use Unix commands** — In the local terminal, type `ls -la`, `grep`, `awk`, or `rsync`. The **Live Webinar** provides a command cheat sheet.
6. **Adjust (optional)** — Change fonts, color schemes, SFTP browser behavior. The **Live Webinar** recommends optimal settings.

## Understanding MobaXterm Windows Core Components — Live Webinar Deep Dive

MobaXterm Windows is not just another terminal emulator. This **Live Webinar** breaks it down into seven core components:

- **SSH client** with graphical SFTP browser — browse remote files as if they were local. The **Live Webinar** shows drag‑and‑drop workflows.
- **X11 server** — display remote Linux GUI apps on your Windows PC. This is the most popular segment of the **Live Webinar**.
- **Unix command-line tools** (over 400+) — use `bash`, `vim`, `tmux`, `rsync`, `curl`, `wget`. The **Live Webinar** includes a live terminal lab.
- **Remote desktop clients** — RDP, VNC, XDMCP, Telnet, and Rlogin. The **Live Webinar** compares performance across protocols.
- **Network utilities** — port scanner, ping, traceroute, nslookup, HTTP/HTTPS browser. The **Live Webinar** integrates these into troubleshooting scenarios.
- **Session manager** — organize servers into folders, import/export sessions. You will master this during the **Live Webinar**.
- **SSH gateway and tunneling** — jump through bastion hosts and create encrypted tunnels. The **Live Webinar** includes a secure tunneling workshop.

All these work together seamlessly. You never need to switch between separate applications after completing the **Live Webinar**. Each component gets a dedicated 15‑minute deep‑dive. The **Live Webinar** also provides downloadable configuration templates for each component.
